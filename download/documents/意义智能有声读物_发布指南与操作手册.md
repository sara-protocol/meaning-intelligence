# 《意义智能》有声读物 · 发布指南与操作手册

> 版本：v3.0｜更新日期：2026-11-27  
> 适用对象：发布维护人员、内容更新人员、智能体与 Web MCP 维护者  
> 项目主页：https://msi.gojj.ccwu.cc  
> 双语有声读物与媒体中心：https://goii.ccwu.cc  
> Cloudflare Pages 部署地址：以当次 wrangler 输出为准，并须通过公网访问检查

## 一、发布包是什么

`意义智能有声读物_发布包` 是双语视听中心与只读 Web MCP 的发布根目录。静态资源无需数据库；`functions/api/mcp.js` 作为 Cloudflare Pages Function 提供可选公共端点。文件数量与体积以最终 `download/manifest.json` 和部署 ZIP 清单为准，不在手册中硬编码。

```text
意义智能有声读物_发布包/
├── index.html                  视听中心入口
├── listen.html                 完整收听页
├── downloads.html              电子书、文档、源码与完整 ZIP 下载中心
├── mcp.html                    双语 Web MCP 说明与只读调用界面
├── project-guide/              双语图文音频项目说明书
├── functions/api/mcp.js        公共只读 Web MCP Pages Function
├── subtitles.json              中文字幕
├── subtitles.vtt               中文 WebVTT
├── subtitles_en.json           英文字幕
├── timeline_en.json            英文章节时间轴
├── assets/                     中文音频、封面、插图与视频
├── assets_en/                  英文音频与插图
└── download/                   白皮书、电子书、PPT、源码与完整交付清单
```

**核心原则：整个文件夹是一个整体，发布、移动、分享时必须原样整体拷贝，不能只发 HTML。**

## 二、本地预览与验收

1. 双击 `index.html`，推荐 Chrome / Edge。
2. 按以下清单验收：
   - [ ] 封面、标题和七个章节入口正常显示。
   - [ ] 点击章节按钮，音频从对应位置播放。
   - [ ] 播放时字幕逐句同步滚动。
   - [ ] 插图正常显示，点击可放大，点空白处关闭。
   - [ ] 切换 EN 后，语音、字幕、插图、章节、正文和 Transcript 同步切换。
   - [ ] 中英发布视频均可播放，时长超过 120 秒，字幕可选择。
   - [ ] 下载中心覆盖 EPUB、DOCX/PDF、PPT、源码、智能体、Web MCP 和完整 ZIP。
   - [ ] 双语项目说明书可切换语言、播放中英音频并同步字幕。
   - [ ] Web MCP 未授权请求被拒绝，授权只读调用不暴露任意文件或命令能力。
3. 浏览器限制本地文件时，在发布包目录执行：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 三、发布前结构校验

在 `meaning-intelligence-publish` 技能目录执行：

```bash
python scripts/build_downloads.py
python scripts/verify_package.py
python scripts/verify_package.py --json
```

`build_downloads.py` 会重建 EPUB、源码 ZIP、下载页、manifest、完整交付包，并在打包前运行当次真实 Chrome 检查。最终验收脚本覆盖：核心文件、JSON、PPTX/DOCX/PDF、EPUB 容器与 spine、SRT/VTT、媒体时长与流、HTML 本地引用、重复 ID、下载 manifest 的路径安全／字节数／SHA-256、源码与完整 ZIP 成员、网页媒体报告、Web MCP JavaScript 语法，以及 V7 证据边界。旧版仅检查核心包的命令通过，不能替代扩展验收。

## 四、生成完整包与部署集

```bash
# 本地完整交付包（含 1080p 母版、原始音频和全部源码）
python scripts/build_downloads.py

# Cloudflare Pages 独立部署集（每个文件小于 25 MiB）
python scripts/build_deploy_zip.py
# 或指定部署 ZIP 输出位置
python scripts/build_deploy_zip.py "D:/publish/意义智能视听中心_部署包.zip"
```

默认生成：

- `deliverables/meaning-intelligence-deploy-staging/`：wrangler 实际部署目录。
- `deliverables/意义智能_部署包.zip`：根目录含 `index.html` 的部署归档。
- `deliverables/deployment-report.json`：成员、排除项、替换媒体、字节数与 SHA-256。

本地发布源目录包含完整交付 ZIP 和超大母版，不能直接上传。部署集会排除完整包、原始超大中文音频、1080p 发布母版和项目说明书中的 1080p 副本，并让 HTML、下载页与 manifest 改用 `audio-web.mp3` 和两个 `*-web.mp4`。部署 ZIP 的 `index.html` 必须位于根目录，不能带外层文件夹。

## 五、Cloudflare Pages 部署

### 5.1 唯一推荐路径：wrangler

历史上仪表盘拖 ZIP / 文件夹多次出现“部署成功但资产不完整”，因此不再使用该路径。

```bash
export CLOUDFLARE_API_TOKEN=<Pages:Edit token>
export CLOUDFLARE_ACCOUNT_ID=<account_id>
cd deliverables/meaning-intelligence-deploy-staging
wrangler pages deploy . --project-name=msi --branch=main --commit-dirty=true
```

- Pages 项目名：`msi`。
- 生产分支：`main`。
- token 权限：`Account → Cloudflare Pages → Edit`。
- 必须从 staging 目录部署，wrangler 才能发现 `functions/`；`functions/api/mcp.js` 必须导出 `onRequest`。
- 日志若出现 `No routes found ... functions`，说明 MCP Function 未被打包，必须修复后重新部署。
- npm 官方源不可达时，可使用 `https://registry.npmmirror.com` 安装 wrangler。
- 本机 curl 的 Schannel 握手可能失败；API 与线上验证优先使用 Python requests。
- 若页面 302 到 Cloudflare Access，由账户管理员明确授权后配置该站点的公网发布；不得擅自放宽其他项目的访问策略。

**未获得用户明确授权时，只打包和验证，不执行部署或修改共享域名配置。**

### 5.2 部署后机器验收

```bash
python scripts/verify_site.py --deep https://<deployment-url>
node scripts/browser_verify.mjs --online https://<deployment-url> deliverables/online-browser-check.json
```

部署前可用本地 Range 服务器检查 staging，不会把完整包规则误套到部署集：

```bash
node scripts/browser_verify.mjs --deployment deliverables/meaning-intelligence-deploy-staging deliverables/deployment-staging-browser-check.json
python scripts/verify_package.py deliverables/意义智能_部署包.zip
```

验收覆盖：

- `/`、`/listen.html`、`/downloads.html`、`/mcp.html`、`/project-guide/`。
- 部署 manifest 中的中英音频、发布视频、二维码、字幕 JSON、SRT/VTT。
- EPUB、白皮书 DOCX/PDF、PPT、源码 ZIP 与最终文档；本地完整交付 ZIP 不上传 Pages。
- 首页标题、收听页、下载中心与项目说明书入口。
- 关键资源非 200 空响应；媒体类型、字节数与部署 manifest 一致，可选全量 SHA-256。
- Range 请求、CORS、Web MCP 未授权拒绝；存在 `MI_MCP_PUBLIC_TOKEN` 时验证授权只读调用，测试 token 不写入日志。

### 5.3 浏览器验收

机器验收通过后，再用浏览器检查：

- 首页和收听页完整渲染。
- 中英文切换、播放、章节跳转、字幕与插图。
- 视频和下载链接。
- 手机宽度布局。
- `goii.ccwu.cc` 与二维码。

脚本验收遇到 403 人机验证或 302 Access 登录时，应记录为外部访问拦截，不得据此宣称线上通过；区分防护页面与真实资源响应后再排查。

## 六、内容更新

### 6.1 更新音频

1. 覆盖 `assets/audio.mp3` 或 `assets_en/audio_en.mp3`。
2. 若时长变化，必须同步更新时间轴：
   - 中文章节时间轴位于 `listen.html` 的 `BI` 数据。
   - 英文章节时间轴位于 `timeline_en.json`。
3. 重新生成 `listen.html`，不要只改音频。

### 6.2 更新字幕

- 中文改 `subtitles.json`，英文改 `subtitles_en.json`。
- 格式为 `{"s": 开始秒, "e": 结束秒, "t": "字幕文本"}`。
- `listen.html` 内嵌了同样数据；改完 JSON 后运行 `build_bilingual.py` 重新生成页面。

### 6.3 更新插图

1. 宽度不超过 1400px 的 JPEG，质量约 82。
2. 中文覆盖 `assets/fig*.jpg`，英文覆盖 `assets_en/img/fig*.jpg`。
3. 图注在 `listen.html` 的 `caps` 对照表中维护。
4. 新增插图需同步页面结构、`data-base` 和 `caps`。

### 6.4 更新文稿

- 中文文稿位于 `listen.html` 的 `.script` 段落。
- 英文源稿位于工作区 `en_script.txt`，使用 `@@SEP@@` 分隔章节，然后运行构建脚本。

### 6.5 重建顺序

```text
修改素材、文稿、文档或源码
→ build_publish.py / build_en_audio2.py / build_bilingual.py
→ build_documents.py 及 PDF 渲染 / 项目说明书与视频生成脚本
→ meaning-agent 全套测试与 Web MCP 聚焦测试
→ build_downloads.py（含当次真实浏览器检查）
→ verify_package.py
→ 本地浏览器验收
→ build_deploy_zip.py
→ 授权后 wrangler 部署独立部署集
→ verify_site.py / browser_verify.mjs --online
→ 自定义域名浏览器验收
→ 生成完整 ZIP、SHA-256 清单并复核下载
```

### 6.6 电子书与下载清单

1. 运行 `meaning-intelligence-publish/scripts/build_downloads.py` 重新生成 EPUB、白皮书副本、PPT、字幕、源码 ZIP、最终 DOCX/PDF 与 `download/manifest.json`。
2. manifest 必须使用相对路径，拒绝 `..`、绝对路径与符号链接越界。
3. 逐项复核文件存在、字节数和 SHA-256；EPUB 必须校验 `mimetype`、`META-INF/container.xml`、OPF manifest/spine 与 XHTML 锚点。
4. 白皮书页数、表数、图数以实际 DOCX/PDF 结构探测为准，不手写估计值。
5. 完整 ZIP 生成后重新打开并校验所有成员，不能只检查 ZIP 文件头；本地完整包保留 1080p 母版，Pages 只接收独立部署集。

### 6.7 Web MCP

- 端点：`POST /api/mcp`，协议版本 `2025-03-26`。
- 公共绑定必须设置至少 32 字符的 `MI_MCP_PUBLIC_TOKEN`；token 只存在部署环境密钥中，不写入前端、日志、文档或提交。
- 可选 `MI_MCP_ALLOWED_ORIGINS` 使用逗号分隔的精确 Origin 白名单。
- 仅暴露资源目录、资源读取、`meaning_analyze`、`meaning_review` 与下载清单；不提供任意 URL、文件、命令或凭据访问。
- 请求体上限 32 KiB；默认每个来源 IP 每分钟 60 次；代理部署必须另配可信客户端识别与限流。
- 机器验收至少覆盖 `initialize`、`tools/list`、`resources/read` 与两个只读工具，并验证未授权、错误方法、超限请求与 CORS。

### 6.8 意义智能智能体

```bash
cd meaning-agent
python -m unittest discover -s tests -v
python -m meaning_agent --help
python -m meaning_agent serve --help
python -m meaning_agent.mcp_public --help
```

- 注册技能必须覆盖 L1–L6；离线模式不依赖外部模型。
- 可选 LLM 只通过环境变量配置，提示词与输出不得绕过安全边界。
- 任何影响外部系统的动作默认 `approval.status=pending`，不得自动执行。
- Web UI 默认仅监听回环地址；公网暴露必须额外配置认证、TLS 与限流。

### 6.9 双语项目说明书与发布视频

- `project-guide/` 必须同时提供中英文正文、配图、音频、SRT/VTT 与离线入口。
- 切换语言时，正文、图注、音频、字幕和下载说明必须一起切换。
- 中英发布视频分别用 ffprobe 检查时长、分辨率、编码、音频流和非静音；时长必须超过 120 秒。
- 字幕时间轴必须与对应音频匹配；不得用中文字幕冒充英文内容。

### 6.10 完整交付包

完整 ZIP 至少包含：Word 项目文档、附件衍生更新版、书稿勘误补充、双语项目说明书、中英视频与字幕、电子书、音频、白皮书、PPT、智能体源码与测试、Web MCP 源码与测试、发布包、生成脚本、验收报告和 SHA-256 清单。网站下载中心与本地交付使用同一份完整 ZIP 或记录可复核的对应哈希。

## 七、二维码与 PPT

正式二维码链接为 `https://goii.ccwu.cc`，出现在讲课版 PPT、MSI 讲解版 PPT 和发布中心。

更换链接时：

1. 重新生成 `assets/qr_site.png` 与 PPT 用二维码。
2. 重截相关页面。
3. 只重组装两份 PPTX，沿用已切分音频，不重复切音频。
4. 使用工作区 `rebuild_pptx_qr.py`。
5. 重建 ZIP、部署并验证。

## 八、常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 首页 200 但空白 | ZIP 带外层目录或根目录无 `index.html` | 用技能脚本重打 ZIP |
| 部署成功但资源 404 | 仪表盘直传截断 | 改用 wrangler，重跑全部验收 |
| 图片全部裂图 | 只上传 HTML 或目录名改变 | 原样上传 `assets/` 与 `assets_en/` |
| 章节跳转错误 | 音频变化但时间轴未更新 | 重新生成时间轴与页面 |
| 字幕逐渐错位 | 音频被替换 | 换回原音频或重新生成字幕 |
| 英文章节高亮错误 | `timeline_en.json` 缺失 | 补传并重跑结构校验 |
| 自定义域名脚本请求 403 | Cloudflare 人机验证 | 用 pages.dev 验证资源，用浏览器验证域名 |
| `upload-token` 10000 | token 权限不足 | 重建设置 Pages:Edit 的 token |
| 微信内不自动播放 | 浏览器自动播放策略 | 引导用户点击播放 |

## 九、安全与版权

- API token 一旦进入对话、日志或命令行历史，应立即在 Cloudflare 控制台轮换或删除。
- `MI_MCP_PUBLIC_TOKEN` 只写入 Pages 环境密钥；不得出现在 `mcp.html`、下载 manifest、源码 ZIP、测试快照或提交中。
- 不在文档、Skill、提交或输出中记录 token。
- 发布前确认音频、文稿、插图和 PPT 的发布权。
- 页面建议标注“有声解读 · 非书籍全文”和版权归属。
- Web MCP 与智能体公网暴露前必须配置 TLS、认证、Origin 白名单、请求体限制、限流和人工批准；本地回环绑定不等于公网安全。
