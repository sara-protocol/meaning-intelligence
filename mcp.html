只读与凭据安全 / Read-only and credential safety

本页面调用同源 /api/mcp。它只读取公开资源，并运行确定性的离线分析；不执行代码、不写文件、不自动批准行动。分析不是实证结论，一切行动仍需人类批准。

令牌必须由部署方通过强随机方式配置为 MI_MCP_PUBLIC_TOKEN（至少 32 个可见 ASCII 字符，并满足服务器的强度策略）。令牌仅保存在当前页面内存中，不写入 URL、Cookie 或浏览器存储；离开页面即清除。请勿分享令牌。

工具边界 / Tool boundaries

  • meaning_analyze: L1–L6 确定性离线结构分析；证据保持 E0，尺度不做加权求和，批准保持 pending。
  • meaning_review: 纳入人工反馈并建议复核；不自动提升证据等级或执行修改。
  • resource_catalog, evidence_levels: 读取正典、证据、章节与技能资源。
  • download_manifest: 只请求同源固定路径 /download/manifest.json；禁用重定向，不转发 Bearer 令牌，不读取清单中列出的文件。

不提供任意文件、URL、代码执行、写入或部署能力。错误消息经过固定文案净化；服务器不记录请求或令牌。

命令行示例 / Command-line example

将主机名替换为实际发布域名，并在 shell 环境中提供强令牌；不要将令牌写入 URL 或提交到仓库。

curl -sS https://YOUR-PUBLICATION-HOST/api/mcp \
  -H "Authorization: Bearer $MI_MCP_PUBLIC_TOKEN" \
  -H "Content-Type: application/json" \
  -H "MCP-Protocol-Version: 2025-03-26" \
  --data '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-03-26","capabilities":{},"clientInfo":{"name":"example-client","version":"1.0"}}}'

部署需要配置 MI_MCP_PUBLIC_TOKEN；跨源访问另需配置 MI_MCP_ALLOWED_ORIGINS。本页面不包含令牌，也不触发部署。
