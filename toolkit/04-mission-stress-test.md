# 工具4 · 组织使命的元认知压力测试
## Tool 4 — Mission Stress Test

*Canon Appendix A · A.2 Organizational-Scale Tools · Tool 4*

> 正文中请一律写「**工具4（使命压力测试）**」。 / The tool identifier `A.4` collides with section `A.4`

## 用途 / Purpose

**中文**　在年度尺度上检验一条组织使命**是否仍然有效**：它对内是否还能约束决策，对外是否还能解释行动，
以及它在五个尺度上是否已经出现长期背离。压力测试不是重写使命，而是**逼出使命失效的证据**——
包括它早已变成墙上一句话却无人据以决策的情形。

**English**　At the annual scale, this test checks whether an organizational mission is **still operative**:
whether it still constrains internal decisions, still explains external action, and whether a long-term
divergence has opened across the five scales. A stress test does not rewrite the mission; it **forces out
the evidence of failure** — including the case where the mission has long been a sentence on a wall that
nobody decides by.

---

## 适用尺度与频率 / Scale and Cadence

- **尺度 / Scale**：组织 / Organizational
- **频率 / Cadence**：每年一次；重大方向变更前加做一次 / Annually, plus once before any major direction change
- **建议做法 / Recommended**：由**不同岗位的人各自独立填写**同一份，再对照差异；差异本身就是数据
  / Have people from **different functions fill the same form independently**, then compare; the divergence is the data

## 关联六层 / Layers Served

| 层 Layer | 本工具做什么 What this tool does here |
|---|---|
| **L3 意义生成** Meaning Generation | 把使命重述为方向／价值／边界三维度（正典 3.2）可判定的表述 |
| **L4 价值评估** Value Assessment | 为主张标注证据等级 E0–E6 与证伪条件；无法标注者退回 L3 |
| **L5 方向选择** Direction Selection | 主层：五尺度检查、尺度冲突的递归校准、偏离阈值与失效日期 |

**为什么不以 L1–L2 为主**：使命的有效性不取决于它写得是否好读。可读性属于界面带，
有效性属于加工带与元带。 / **Why not L1–L2**: a mission's validity is not a readability property.
Readability is the interface band; validity is the processing and meta bands.

## 判读标准 / How to read the result

**中文**
- **偏离阈值（正典给出）**：一级修正 <10%、二级修正 10–30%、三级修正 >30%。这是本表**唯一**的数值判读线。
- **L6 的失败阈值（正典给出）**：若组织级归零的检验出现「**RCT 无显著差异（d<0.3）**」，
  则归零类动作只能保留为规程，不再主张有效性。
- **正典未给出阈值**：使命有效性本身、三维度各自的可观测比例、五尺度一致／冲突的计数，
  正典均未给出数值分界。**本表不设判读线，只做记录与纵向比对。**
- 特别提醒：**「内部一致」与「符合直觉」不是提升证据等级的正当理由**（见
  [`../docs/failure-matrix.md`](../docs/failure-matrix.md) 第二节）。

**English**
- **Deviation thresholds (canon)**: level-one <10%, level-two 10–30%, level-three >30% — the **only**
  numerical reading line here.
- **L6's failure threshold (canon)**: if zeroing is tested and shows **no significant difference
  (d<0.3)**, zeroing-type actions remain procedural only, with no efficacy claim.
- **No threshold in the canon** for mission validity itself, for the observable share of each dimension, or
  for counting scale agreements. **Record and compare; read no line into them.**
- Note in particular: **internal consistency and intuitive appeal are not valid grounds for raising an
  evidence level** (failure matrix §2).

## 失败即删的提示 / If Falsified, Revise or Withdraw

1. 若 **H8（尺度背离-危机）被证伪**——出现「长期背离却无危机」的反例——第 3 节的五尺度一致性检查
   失去预测力，本工具须**重估五尺度模型**，不得继续据一致性判定使命健康。
   / If **H8** is falsified by a case of long divergence without crisis, §3 loses its predictive force and
   the five-scale model must be reassessed.
2. 若 **H7（跨尺度一致性-生存）被证伪**，「一致者生存更久」不再成立，第 3 节不能作为生存性判据。
   / If **H7** is falsified, §3 cannot serve as a survival criterion.
3. 若 **H2（意义结构的三个维度）被证伪**——即意义判断方差被单一维度解释 >90%——第 2 节的三维度拆解
   应被**重构或删除**。 / If **H2** is falsified (>90% of variance on one dimension), §2 must be rebuilt or removed.
4. 若 **H4（势能驱动行动）被证伪**，使命与后续行动之间的关联主张失效，本工具降级为叙事盘点。
   / If **H4** is falsified, the mission-to-action claim fails and the tool becomes a narrative inventory.

## 边界 / Boundaries

- **不能替代专业判断**：不替代法律、财务、合规或行业专业判断。压力测试不是审计。
  **Does not replace professional judgment** — legal, financial, compliance, or domain expertise.
- **不承诺正确答案**：它检验使命是否还有效，不告诉你应该改成什么，也不承诺「更值得」的使命存在。
  **Promises no correct answer**: it tests whether the mission still operates, not what it should become.
- **不适用于无主体系统**：纯物理系统不适用。
  **Not applicable to subject-less systems.**
- **文化敏感性**：五尺度中「国家」与「人类」两端的含义高度依赖文化背景。
  **Cultural sensitivity**: the national and human ends of the scale set are culture-dependent.
- **过度元认知可致决策瘫痪**：若压力测试连续两轮只产出「使命需进一步讨论」而无任何决策，
  应停止测试并改由负责人直接给出可执行的使命表述。
  **Excessive metacognition can cause decision paralysis**: if two consecutive rounds produce only "the
  mission needs further discussion" and no decision, stop and have the accountable owner state one.
