# 意义智能实践工具模板 / Meaning Intelligence Practice Toolkit

> 本目录是正典附录 A 的**可填写实践工具模板集**：把六层应用栈的每一层落成可以打印、可以填、可以归档的表单。
> This directory is the **fillable practice-tool template set** for Canon Appendix A: each layer of the six-layer stack reduced to a form you can print, fill in, and archive.

理论定义、阈值与证据等级一律以正典《意义智能：意义文明的认知操作系统》V7.0 为准；本目录只做**可填写化**，
不新增、不改写任何构念或数字。正文中的层名与三带划分与 [`../msi/config.json`](../msi/config.json) 一致。
Construct definitions, thresholds, and evidence levels belong to the canon. This directory only makes them
**fillable**; it adds and rewrites nothing. Layer names and bands follow [`../msi/config.json`](../msi/config.json).

## ⚠️ 先读这一段：附录 A 有**两套会撞车的编号** / Read this first: Appendix A has **two colliding numbering systems**

正典附录 A 里同时存在两套编号，它们的字面形式相同但指的不是同一件事：

The canon's Appendix A carries two numbering systems whose literal forms look alike but mean different things:

| 编号体系 | 例子 | 指的是什么 |
|---|---|---|
| **章节编号** | `A.1` / `A.2` / `A.3` / `A.4` | 附录 A 里的**分类章节**：A.1 个人尺度工具 / A.2 组织尺度工具 / A.3 城市尺度工具 / **A.4 通用工具** |
| **工具编号** | `A.1` / `A.4` / `A.10` | 附录 A 里的**具体工具**：A.1 意义自检卡 / **A.4 使命压力测试** / A.10 归零安全检查清单 |

**撞车点：章节 `A.4` 是「通用工具」，工具 `A.4` 是「使命压力测试」。两者完全无关。**

**The collision: section `A.4` is "General Tools"; tool `A.4` is the "Mission Stress Test". They are unrelated.**

因此在本目录内：

1. **一律不使用裸编号**（如单独的 `A.4`）。写编号时必须带名称：**「工具4（使命压力测试）」**或**「附录 A.4 通用工具」**。
2. 每份模板顶部都有一个**「出处」**行，同时标注**章节**与**工具编号**，例如：
   `出处：正典附录 A · A.1 个人尺度工具 · 工具1`
3. 工具的主标识是**「工具N + 名称」**，不是编号。引用时请照抄这一形式。
4. 如果你在其他文档里看到裸写的 `A.4`，**它是有歧义的**，请回到正典确认后按上述形式补全名称。

In this directory: never write a bare identifier such as `A.4`. Always attach the name —
*Tool 4 (Mission Stress Test)* or *Appendix A.4 General Tools*. Every template opens with a **Source** line
naming both the section and the tool identifier. The primary identifier is **"Tool N + name"**, not a number.
Any bare `A.4` elsewhere is ambiguous; resolve it against the canon before citing.

## 怎么用 / How to use

- **打印**：每份模板都是纯 Markdown 表格与复选框，A4 打印后手填。若某张表过长，按「填写区」小节拆页打印。
  **Print**: each template is plain Markdown tables and checkboxes, sized for A4. If a table runs long, print the "填写区" section on its own page.
- **复制到笔记软件**：把整份文件复制为一条笔记，建议在文件名前加年份或周期（如 `01-意义自检-2026W07`）。
  **Copy into a note app**: paste the whole file as one note; prefix the title with a year or cycle (e.g. `01-self-check-2026W07`).
- **作为团队工作坊材料**：工具4、工具5、工具6、工具8 可直接作为会议材料；工具4 与工具5 建议由**不同的人**填写同一份，再对照差异。
  **As workshop material**: Tools 4, 5, 6, and 8 work as meeting materials; for Tools 4 and 5, have **different people** fill the same form independently, then compare.
- **归档与比对**：判读标准一栏多数写着「正典未给出阈值，本表不设判读线，只做记录」——这不是缺陷。
  这类工具的价值来自**纵向可比**：多轮记录之间的差异本身就是材料。
  **Archive and compare**: many "How to read the result" sections say "no threshold in the canon; record only".
  That is not a defect — such tools earn their value from **longitudinal comparability**.

## 两条共同的自我约束 / Two constraints shared by every template

1. **不得事后改写阈值。** 任何阈值一经填写即为预注册；事后放宽属于 HARKing（见 [`../CONTRIBUTING.md`](../CONTRIBUTING.md)）。
   **Never rewrite a threshold after the fact.** Once filled in, a threshold is preregistered; relaxing it later is HARKing.
2. **正典没有给的数字，不要自己补。** 模板中凡正典未给出阈值的字段，一律留空只做记录，禁止填入自行发明的分数线。
   **Do not invent numbers the canon does not give.** Where the canon states no threshold, the field stays a record only.

这些模板是**待检验的组织工具**，不是已证实的发现。六层栈本身是一个整合结构，其证据等级为

integrative structure at evidence level **E0 (conceptual)**, not yet independently tested; per-layer
operationalization levels are in [`../docs/evidence.md`](../docs/evidence.md). If a simpler partition with
greater explanatory power emerges, the stack should be **replaced**, not defended.

若某份模板所依赖的假设被证伪，该模板应被**修订或废弃**；处置规则见
[`../docs/failure-matrix.md`](../docs/failure-matrix.md) 第二节。

If an assumption a template rests on is falsified, that template should be **revised or withdrawn**; the
disposition rules are in [`../docs/failure-matrix.md`](../docs/failure-matrix.md) §2.
