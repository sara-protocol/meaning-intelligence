# 工具2 · 个人意义归零协议
## Tool 2 — Personal Meaning Zeroing Protocol

**出处 / Source**：正典附录 A · A.1 个人尺度工具 · 工具2 · *Canon Appendix A · A.1 Individual-Scale Tools · Tool 2*

## 用途 / Purpose
**中文**　在年度尺度上，对个人当前的意义方向做一次**有控制的重置**，而不是等它僵化到无法自我修正。本协议执行正典 7B.4「主动归零」的**五步软归零流程**：**预检 → 悬置 → 回归元问题 → 重建 → 试运行**，**每一步都设有一个安全检查点**。归零不是推倒重来，而是回到更高一层的起点；若一次归零后与归零前完全重合，说明这一轮没有产生意义增量。
**English**　At the annual scale, this performs a **controlled reset** of a person's meaning direction before it ossifies past self-correction. It runs the canon's §7B.4 *active zeroing* as a **five-step soft zeroing flow**: **Pre-check → Suspension → Return to the meta-question → Reconstruction → Trial run**, with **one safety check point at every step**. Zeroing is not starting over; it is returning to a higher entry point. If a cycle coincides exactly with the previous one, no meaning increment was produced.

## 适用尺度与频率 / Scale and Cadence
- **尺度 / Scale**：个人 / Individual
- **频率 / Cadence**：每年一次，固定日期；归零**前**先完成工具10 / Annually on a fixed date, after passing Tool 10
- **前置动作 / Prerequisite**：未通过 [`10-zeroing-safety-checklist.md`](10-zeroing-safety-checklist.md) 不得启动 / Do not start without passing it

## 关联六层 / Layers Served
| 层 Layer | 本协议做什么 What this protocol does here |
|---|---|
| **L5 方向选择** Direction Selection | 悬置与重建阶段重新执行五尺度检查与偏离阈值声明（三级修正） |
| **L6 反思与审视递归** Recursive Reflection and Review | 主层：让系统审视自己的审视；三特性 MCA（7B.2）· SA（7B.3）· AZ（7B.4） |

**为什么以 L6 为主**：只有元带能改写下层前提。归零若不动 L1–L4 的前提（「什么才算值得处理的材料」），它就只是一次年度总结。 / **Why L6 leads**: only the meta band rewrites the premises below it. A zeroing that leaves the L1–L4 premises untouched is only an annual review.

## 判读标准 / How to read the result
**中文**
- **偏离阈值（正典给出）**：一级修正 <10%、二级修正 10–30%、三级修正 >30%。这是本协议**唯一**的数值判读线。
- **螺旋图几何（正典给出）**：归零后的落点 L1′ 与原点 L1 处于**同一角度、更大半径**；若第二轮与第一轮**完全重合**，说明这一轮没有产生意义增量。
- **归零准备度 RZ、意义清晰度 MC、螺旋深度 SD** 出自正典附录 B 表，但**正典未给出阈值**；本表不设判读线，只做记录与纵向比对。
- 其余一切「本次归零得几分」的分数线都是自造的，不属于正典。
**English**
- **Deviation thresholds (canon)**: level-one <10%, level-two 10–30%, level-three >30% — the **only** numerical line here.
- **Spiral geometry (canon)**: the post-zeroing entry point sits at the **same angle and a larger radius**; an **exact coincidence** means no meaning increment.
- **RZ, MC, and SD** come from Canon Appendix B, but **the canon states no threshold**; record and compare only.
- Any other "score for this zeroing" would be invented and is not canon.

## 失败即删的提示 / If Falsified, Revise or Withdraw
本协议直接依赖 **H12（归零防僵化）**、**H13（元认知-判断质量）**、**H14（无归零-僵化）**：
1. **H12 被证伪**（归零并不防止僵化）⇒ 整条五步流程应被**删除**，而不是保留为「好习惯」。 / **H12 falsified** ⇒ delete the whole five-step flow.
2. **H14 被证伪**（不归零也不必然僵化）⇒ 年度归零的必要性主张失效，本协议降级为**可选**事项。 / **H14 falsified** ⇒ annual zeroing becomes optional.
3. **H13 被证伪**（元认知不提升判断质量）⇒ 步骤 3 的元问题填写应被移除，其价值主张正来自 H13。 / **H13 falsified** ⇒ remove Step 3.
4. 若 L6 触及失败阈值（**RCT 无显著差异，d<0.3**）⇒ **放弃有效性主张，仅保留为操作规程**。 / If L6 reaches its threshold (**RCT, d<0.3**) ⇒ drop the efficacy claim; keep it procedural.

## 边界 / Boundaries
- **不能替代专业判断**：不替代医疗、法律、心理治疗的专业判断；归零不是治疗。 / **Does not replace professional judgment** — medical, legal, or clinical. Zeroing is not therapy.
- **不承诺正确答案**：它输出「更值得的方向」，不是唯一答案。 / **Promises no correct answer**; it offers a more worth-going direction, not a unique one.
- **不适用于无主体系统**：纯物理系统不适用。 / **Not applicable to subject-less systems.**
- **文化敏感性**：元问题与悬置期的具体做法需适配文化背景。 / **Cultural sensitivity**: the meta-question and suspension practices need cultural adaptation.
- **过度元认知可致决策瘫痪**：若预检连续两轮无法通过安全检查点 1，应停止归零并转人工判断。 / **Excessive metacognition can cause decision paralysis**: if check 1 fails twice in a row, stop and seek human judgement.
