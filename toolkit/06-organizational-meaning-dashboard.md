# 工具6 · 组织意义监测仪表盘
## Tool 6 — Organizational Meaning Dashboard

**出处 / Source**：正典附录 A · A.2 组织尺度工具 · 工具6
*Canon Appendix A · A.2 Organizational-Scale Tools · Tool 6*

---

## 用途 / Purpose

**中文**　按季度把组织的意义健康状态固定在一页上，使「意义」和其他经营指标一样**可被持续观测**。
它不解释原因、不提出对策，只做三件事：给关键判断标注证据强度（L4）、跟踪 PE 四个变量的变化方向、
记录方向一致性的漂移幅度。仪表盘的价值来自**季度之间的可比性**，不来自任何单季读数。

**English**　Each quarter this dashboard fixes the organization's meaning state onto one page so that
"meaning" is observed continuously, like any other operating indicator. It explains nothing and proposes
nothing; it does three things: label key judgments with evidence strength (L4), track the direction of
change of PE's four variables, and record how far direction consistency has drifted. Its value comes from
**comparability across quarters**, not from any single reading.

---

## 适用尺度与频率 / Scale and Cadence

- **尺度 / Scale**：组织 / Organizational
- **频率 / Cadence**：每季度一次；同一填表人、同一口径，避免口径漂移 / Quarterly, same compiler and same definitions to prevent drift
- **存档 / Archiving**：每季一页，按时间顺序装订，不覆盖历史 / One page per quarter, kept in order; never overwrite history

---

## 关联六层 / Layers Served

| 层 Layer | 本仪表盘做什么 What this dashboard does here |
|---|---|
| **L4 价值评估** Value Assessment | 主层：为每个判断标注 E0–E6 证据等级与不确定性；估计 PE 变化方向 |
| **L5 方向选择** Direction Selection | 记录 DC 漂移与偏离阈值触发情况（三级修正） |
| **L1–L3** | 覆盖：记录的输入结构（L1）、可交互产物数量（L2）、候选意义结构数量（L3），均为计数项 |

**为什么 L4 是主层**：仪表盘的每一项都必须带证据强度，否则它只是一张 KPI 表。
**Why L4 leads**: every entry must carry evidence strength, or the dashboard is just a KPI sheet.

## 判读标准 / How to read the result

**中文**
- **偏离阈值（正典给出）**：一级修正 <10%、二级修正 10–30%、三级修正 >30%。这是本表**唯一**的数值判读线。
- **证据等级（正典给出判据）**：E0–E6 的逐级判据见 [`../docs/evidence.md`](../docs/evidence.md) 第一节。
  等级描述**知识状态**，不是质量评分，也不构成升级任务。
- **正典未给出阈值**：PE 的绝对值、A／C／G／M 的数值分界、DC 的健康区间、计数项的正常范围——
  正典一律未给出。**本表不设判读线，只做记录与季度间纵向比对。**
- **禁止的事**：本表不产生任何综合健康分。任何「意义健康指数」都是自造的，不属于正典。

**English**
- **Deviation thresholds (canon)**: level-one <10%, level-two 10–30%, level-three >30% — the **only**
  numerical reading line here.
- **Evidence levels (canon criteria)**: level-by-level criteria for E0–E6 are in
  [`../docs/evidence.md`](../docs/evidence.md) §1. A level describes **knowledge state**, not quality, and
  is not an upgrade task.
- **No threshold in the canon** for absolute PE, for numerical cuts on A / C / G / M, for a healthy DC
  range, or for normal counts. **Record and compare across quarters.**
- **Prohibited**: this dashboard yields no composite health score. Any "meaning health index" would be
  invented and is not canon.

## 失败即删的提示 / If Falsified, Revise or Withdraw

1. 若 **H4（势能驱动行动）被证伪**，第 2 节的 PE 变量跟踪不再构成任何前瞻性记录，该节应删除或改为
   纯描述字段。 / If **H4** is falsified, §2 stops being a forward-looking record; remove or make it descriptive.
2. 若 **H13（元认知-判断质量）被证伪**，「标注证据等级能提升判断质量」这一前提失效，
   第 1 节的证据等级列应停止使用。 / If **H13** is falsified, drop the evidence-level column in §1.
3. 若 **H8（尺度背离-危机）被证伪**，第 4 节的冲突记录失去预测力，须重估五尺度模型。
   / If **H8** is falsified, §4 loses predictive force; reassess the five-scale model.
4. 若 L4 触及失败阈值（**标注与判断质量无相关**），本仪表盘须**退回定性评估**。
   / If L4 reaches its threshold (**no correlation between labelling and judgment quality**), revert to
   qualitative assessment.
5. 若 L6 触及失败阈值（**RCT 无显著差异，d<0.3**），按
   [`../docs/failure-matrix.md`](../docs/failure-matrix.md) 保留为规程，不再主张有效性。

## 边界 / Boundaries

- **不能替代专业判断**：不替代财务、法律、合规、安全与行业专业判断。
  **Does not replace professional judgment** — financial, legal, compliance, safety, or domain expertise.
- **不承诺正确答案**：仪表盘显示状态，不给处方，也不承诺某个 PE 方向必然带来好结果。
  **Promises no correct answer**; it shows state, prescribes nothing, and promises no outcome.
- **不适用于无主体系统**：纯物理系统不适用。
  **Not applicable to subject-less systems.**
- **文化敏感性**：尺度定义与「意义协调度」的具体口径需按文化背景适配。
  **Cultural sensitivity**: scale definitions and the operationalization of meaning coordination need adaptation.
- **过度元认知可致决策瘫痪**：若连续两季仪表盘只产出记录而无任何决策，应停止填报并改为
  年度一次，或直接取消该仪表盘。
  **Excessive metacognition can cause decision paralysis**: if two consecutive quarters produce records but
  no decision, drop to annual or retire the dashboard.
