# 工具3 · 生命叙事螺旋图
## Tool 3 — Life Narrative Spiral Map

**出处 / Source**：正典附录 A · A.1 个人尺度工具 · 工具3
*Canon Appendix A · A.1 Individual-Scale Tools · Tool 3*

---

## 用途 / Purpose

**中文**　把多年的意义变化画成一张**螺旋**，而不是一条时间线或一段上升曲线。螺旋图关心的不是
「我现在水平多高」，而是**本轮与上一轮相比产生了多少意义增量**——正典用螺旋深度 SD 表示。
它让「回到同一个问题」与「原地打转」在纸面上区分开：同一角度、更大半径是螺旋；完全重合是空转。

**English**　This map draws years of meaning change as a **spiral** rather than a timeline or a rising
curve. It does not ask "how high am I now" but **how much meaning increment this cycle produced over the
last** — the canon's spiral depth, SD. It separates "returning to the same question" from "going in
circles" on paper: same angle, larger radius is a spiral; exact coincidence is idling.

---

## 适用尺度与频率 / Scale and Cadence

- **尺度 / Scale**：个人 / Individual
- **频率 / Cadence**：每年一次，通常在工具2（个人意义归零协议）之后填写 / Annually, normally after Tool 2
- **累积性 / Cumulative**：本图**跨年累加**，不建议只保留当年一页 / Keep every year on file; do not keep only the current page

## 判读标准 / How to read the result

**中文**
- **正典给出几何判读**：落点与上一轮**同一角度、更大半径**为螺旋；**完全重合**为未产生意义增量。
- **正典给出速率判读**：**H6——螺旋速率过快或过慢均致危机**（倒 U 型）。即「越快越好」不成立，
  「一直很慢」也不成立，两端都不是好状态。
- **正典未给出阈值**：螺旋深度 SD、系缚强度 BS 的具体数值分界，正典未给出；本表不设判读线，只做记录
  与纵向比对。
- 本表**不给**任何「健康区间」「危险值」的数字；凡本表未引用的数字，均不属于正典。

**English**
- **Canon geometry**: same angle with a **larger radius** is a spiral; **exact coincidence** means no
  meaning increment.
- **Canon rate reading**: **H6 — a spiral rate that is too fast or too slow both lead to crisis**
  (inverted-U). "Faster is better" does not hold, and neither does staying slow; both extremes are bad.
- **No threshold in the canon**: the canon gives no numerical cut for SD or BS. Record and compare over
  time; do not read a line into them.
- This map states **no** "healthy range" or "danger value". Any number not quoted above is not canon.

## 失败即删的提示 / If Falsified, Revise or Withdraw

1. 若 **H12（归零防僵化）被证伪**，螺旋图所记录的「归零后半径增大」这一现象不再支持任何有效性主张，
   本图应降级为纯描述性年表。 / If **H12** is falsified, the "radius grows after zeroing" observation
   supports no efficacy claim; the map is demoted to a descriptive chronicle.
2. 若 **H14（无归零-僵化）被证伪**，「不归零的年份半径不增」这一读法失效，第 1 节的半径列应停止使用。
   / If **H14** is falsified, the reading "years without zeroing show no radius growth" fails; drop the radius column.
3. 若 **H6（螺旋速率倒 U 型）被证伪**，本图的速率判读整节删除，只保留几何判读。
   / If **H6** is falsified, the rate reading is deleted entirely, leaving only the geometry.
4. 若 L6 触及失败阈值（**RCT 无显著差异，d<0.3**），本图按
   [`../docs/failure-matrix.md`](../docs/failure-matrix.md) 保留为操作规程，不再主张有效性。
   / If L6 reaches its threshold (**RCT, d<0.3**), the map remains a procedure without an efficacy claim.

## 边界 / Boundaries

- **不能替代专业判断**：不替代医学、法律、心理治疗的专业判断；螺旋图不是诊断工具。
  **Does not replace professional judgment**; the spiral map is not a diagnostic instrument.
- **不承诺正确答案**：螺旋图不判定「哪一年的方向是对的」。
  **Promises no correct answer**; it does not adjudicate which year's direction was right.
- **不适用于无主体系统**：纯物理系统不适用。
  **Not applicable to subject-less systems.**
- **文化敏感性**：生命叙事的节点（求学、成家、迁徙等）高度依赖文化背景，不宜套用统一模板。
  **Cultural sensitivity**: life-narrative milestones are culture-dependent; do not impose one template.
- **过度元认知可致决策瘫痪**：逐年重述若开始阻碍当下行动，应缩短为一行摘要。
  **Excessive metacognition can cause decision paralysis**: if restatement starts blocking present action, cut it to one line.
