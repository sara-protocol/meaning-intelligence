# 工具1 · 意义自检卡
## Tool 1 — Meaning Self-Check Card

**出处 / Source**：正典附录 A · A.1 个人尺度工具 · 工具1 · *Canon Appendix A · A.1 Individual-Scale Tools · Tool 1*

## 用途 / Purpose
**中文**　在信息供给远超个人认知带宽的日常条件下，把「我又被推着走了一天」变成一张可判断的记录。它只做一件事：把当天的输入压到可处理的带宽内、分离核心事实与待决问题，并给每条判断标注证据强度。它不解释人生，也不回答「我该不该换工作」——那是 L5 的事。
**English**　Under everyday conditions where information supply far exceeds one person's bandwidth, this card turns "I was pushed along again today" into a record that can be judged. It does one thing: compress each day's input to a workable bandwidth, separate core facts from open questions, and label every judgment with its evidence strength. It does not explain a life, and it does not answer "should I change jobs" — that belongs to L5.

## 适用尺度与频率 / Scale and Cadence
- **尺度 / Scale**：个人 / Individual
- **频率 / Cadence**：每日轻填（≤5 分钟）；每周重填一次完整版 / Daily light pass (≤5 min); one full weekly pass
- **载体 / Medium**：打印 A4，或笔记软件中的一条固定笔记 / A4 printout, or one pinned note in a note app

## 关联六层 / Layers Served
| 层 Layer | 本卡做什么 What this card does here |
|---|---|
| **L1 减负** Cognitive Load Reduction | 主层：把当日输入压到可处理带宽，分离「核心事实」与「待决问题」 |
| **L2 可体验** Experiential Rendering | 次要：把「今天到底发生了什么」重述为可回看的一条记录 |
| **L3 意义生成** Meaning Generation | 记录当日一条方向／价值／边界的初步定位（三维度，正典 3.2） |
| **L4 价值评估** Value Assessment | 给每条判断标注证据等级 E0–E6，并写下它的证伪条件 |

**为什么不覆盖 L5–L6**：方向选择与归零是**低频高代价**的动作，放进日更表会退化成打勾仪式。L5–L6 由工具2（个人意义归零协议）与工具3（生命叙事螺旋图）承担。 / **Why not L5–L6**: direction selection and zeroing are **low-frequency, high-cost** acts; on a daily form they degrade into box-ticking. They belong to Tool 2 and Tool 3.

## 判读标准 / How to read the result
**中文**
- **本表不设阈值。** 正典未为本卡给出任何数值判读线；它的作用是**记录与纵向比对**。任何「今天该得几分」的分数线都是自造的，不属于正典。
- 唯一可用的判读来自**本框架以外的既有标尺**：证据等级 E0–E6 的逐级判据见 [`../docs/evidence.md`](../docs/evidence.md) 第一节。
- **唯一可对照的预注册阈值不在本卡这一层**：L1 减负的失败阈值是「降维后决策质量无提升（d<0.3）」，见 [`../docs/failure-matrix.md`](../docs/failure-matrix.md)。本卡记录的是减负的**输入与过程**，不能判定该阈值是否被触及。
**English**
- **This card sets no threshold.** The canon gives no numerical reading line for it; its job is **recording and longitudinal comparison**. Any "score for today" would be invented.
- The only usable reading comes from a scale defined **outside this card**: the level-by-level criteria of E0–E6 in [`../docs/evidence.md`](../docs/evidence.md) §1.
- **The one comparable preregistered threshold is not at this layer**: L1's failure threshold is "no improvement in decision quality after reduction (d<0.3)" — see [`../docs/failure-matrix.md`](../docs/failure-matrix.md). This card records the **input and process**, and cannot settle that threshold.

## 失败即删的提示 / If Falsified, Revise or Withdraw
1. 若 **H4（势能驱动行动）**被证伪，「意义定位」不再构成行动的有效前置记录，第 3 节应删除或改为纯描述字段。 / If **H4** is falsified, §3 stops being a valid precursor record of action; remove it or make it descriptive.
2. 若 L1 触及失败阈值（降维后决策质量无提升，**d<0.3**），本卡应失去**有效性主张**，按 [`../docs/failure-matrix.md`](../docs/failure-matrix.md) 第二节降级为纯操作规程或废弃。 / If L1 reaches its threshold (**d<0.3**), this card loses any **efficacy claim** and is demoted or withdrawn.
3. 若 L3 触及失败阈值（意义判断方差被单一维度解释 **>90%**，即 **H2 被证伪**），第 3 节的三维度表格必须**重构**，不得继续使用。 / If L3 reaches its threshold (**>90%** on one dimension, i.e. **H2 falsified**), §3 must be rebuilt.

## 边界 / Boundaries
- **不能替代专业判断**：不替代医学、法律、工程或心理治疗的专业判断。 / **Does not replace professional judgment** — medical, legal, engineering, or clinical.
- **不承诺正确答案**：它帮你把材料排整齐，不告诉你该选哪个方向。 / **Promises no correct answer**; it orders material, not directions.
- **不适用于无主体系统**：纯物理系统不适用。 / **Not applicable to subject-less systems.**
- **文化敏感性**：维度与措辞需按使用者的文化背景调整。 / **Cultural sensitivity**: dimensions and wording need adaptation.
- **过度元认知可致决策瘫痪**：每日检查若超过 5 分钟仍在继续，即是此风险的显形，应削减条目。 / **Excessive metacognition can cause decision paralysis**: a daily pass running past five minutes shows that risk; cut items.
