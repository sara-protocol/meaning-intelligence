## 三、已确认冲突 / Confirmed Conflicts

### 3.1 六层来源 / Provenance of the Six Layers

- 正典的 L1–L3 是元意义、结构意义、情境意义，后在 §8.1 重释为连续光谱带。
- 正典不存在“减负—可体验—意义生成—价值评估—方向选择—反思递归”的固定六层。
- 仓库六层栈、三带和 MSI 是**工程扩展（E0）**，只能声明概念关联，不能声称层名与层定义均取自正典。
- L1 的 §1.1 / A.1、L2 的第3章 / M1 没有对应层定义；L3/L5/L6 只能关联到 §3.2/§8.1、第4章、§7B.2–§7B.4 与相关 H 编号。

### 3.2 E3 / E6 语义 / Evidence Semantics

| 等级 | V7.0 正典 | 仓库旧表述（已废止） |
|---|---|---|
| E3 | 有预注册假设 + 数据收集中 | 在新数据上给出方向与量级正确的预测 |
| E6 | 跨情境 / 跨文化 / 跨时间泛化 | 由本框架之外的领域独立确认 |

未版本化的标准升级会造成证据等级虚高。现行文档已统一回 V7.0 定义。

### 3.3 失败矩阵 / Failure Matrix

- 正典附录 D.7 是 SG、Spectrum Spiral、Witness→Leap、MI-AI、Weaving Sovereignty 五模块。
- 仓库旧“六层失败矩阵”不是正典矩阵，且阈值与 `config.json` 不一致。
- 仅 L3 与 H2 直接对应；L5 与 H7/H8 相关但不等同；L6 混用了 H12、H13、H14 三个不同对象。
- 现行文档已拆成“正典五模块 / H1–H18 / 工程草案”三层。

### 3.4 MSI 数字 / MSI Counts

- README 旧称“120 个粒子收敛为 12 个节点”。
- `config.json` 的过载计数为 **45**；结构图是 **2 个节点**；中间提炼 **3 条核心语句**；L3 示意使用 **9 个点**。
- README 已按实际配置修正。
